# Barcode pantry products

- Scan a supported EAN/GTIN with the browser camera or enter it manually.
- Review Open Food Facts details or add an unknown product by hand; reuse the household catalog on later scans.
- Track package counts or amounts in dated batches, edit locations/expiry/quantity, and merge repeated additions.
- Keep branded products separate from recipe ingredients, with optional nutrition and an ingredient association.
- Preserve OFF attribution and license information, including in catalog exports.

See [the feature and operating notes](../product-catalog.md).
